# 💰 M-Pesa Full-Stack App

Complete M-Pesa payment solution with FastAPI, Bootstrap, and SQLite.

## Features

- ✅ STK Push payments
- ✅ Transaction history (saved to database)
- ✅ Admin dashboard with statistics
- ✅ Real-time status updates
- ✅ Bootstrap UI

## Quick Start

```bash
git clone https://github.com/asundah/mpesa-fullstack-app.git
cd mpesa-fullstack-app
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
uvicorn app.main:app --reload

Pages
/ - Make payment

/transactions - View history

/dashboard - Statistics

Author
Amos Asunda (@asundah)
```
